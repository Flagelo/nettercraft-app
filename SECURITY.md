# Política de Segurança (Security Policy)

## Relato de vulnerabilidades

Não abra issues públicas nem pull requests públicos para relatar falhas de segurança, exposição de segredos ou vulnerabilidades exploráveis.

Envie o relato de forma privada por meio dos **GitHub Security Advisories** deste repositório:

- `https://github.com/Flagelo/Nettercraft/security/advisories/new`

Inclua na notificação:

- Descrição do problema e impacto potencial;
- Passos mínimos ou prova de conceito para reprodução;
- Arquivos, workflows ou versões afetadas.

Não envie credenciais reais, tokens ou dados sensíveis de terceiros no relato.
